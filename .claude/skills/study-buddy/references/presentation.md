# Presentation细则

做pre的评分维度、结构、页数与时长、讲稿、Q&A。Presentation用。分工见[group-work.md](group-work.md)，语言、翻译、画图、自查见[deliverables.md](deliverables.md)。

## 评分维度

作业给了评分标准时，以它为准。没给时用下面这套通用维度（依据AAC&U VALUE口头表达量规，以及CMU、MIT的pre评分标准）：

| 维度 | 看什么 |
|---|---|
| 内容与中心信息 | 有没有一个听众能复述的核心信息；论据是否支持它 |
| 结构 | 引言、主体、结论是否清楚，过渡是否自然 |
| 表达 | 语速、清晰度、是否照本宣科 |
| 支撑材料 | 例子、数据、案例是否具体、可靠 |
| 视觉辅助 | 页面是否简洁，图表是否帮助理解 |
| 互动 | 是否和听众有眼神、提问或停顿 |
| 时间控制 | 是否在规定时长内讲完 |

## 要求清单

从作业要求和评分标准提取并逐条列出：时长、页数、必须包含的内容、评分维度、个人或小组、提交形式。后面的自查就对着这张清单。

## 结构

- 按“引言、主体、结论”组织。引言说明主题和要讲什么，主体分2–4个要点，结论回到一个核心信息
- 结尾落在一个核心信息上，听众只能记住一件事
- 小组pre：先搭全组的总结构，再只展开用户负责的部分，并写好和前后同学的衔接语

## 页数与时长

- 页数按大约每分钟1页估算。这是经验值，没有研究依据，内容密集的页可以占更久
- 先定总页数，再排每页的要点。封面和致谢不算在内容页的时间里，但要算在总页数里

## PPT大纲

每页写：标题、2–4个要点、该页要不要图表。

- 标题用结论句，如“公关比广告更可信”，不用“公关与广告”这类话题词
- 要点是短语，不是整句。整句放进讲稿
- 一页只讲一件事

## 讲稿

- 口语化，按“一页一段”写。每页开头有承接上一页的一句
- 长度按时长估：中文大约每分钟200–250字，英文大约每分钟130–150词（经验值）。用户试讲计时后再调整
- 讲稿写进pptx的备注栏
- 小组pre只写用户负责的页，开头加和前一位同学的衔接，结尾加交棒给下一位的话

## Q&A

- 预判5–8个听众或老师可能问的问题，每个写一段简答。问题来源：评分标准里的维度、材料里的薄弱点、概念辨析
- 回答方法：先听完问题，复述一遍确认，再逐点简洁作答，答完停下，不自己加料
- 答不出时的说法：承认边界、说明已知的部分、给出之后跟进的方式
- 小组pre中，指定统筹者主持Q&A，用户只答自己负责部分的问题

## 坑点

- 不要把整页讲稿贴到页面上。页面是给听众看的，讲稿是给用户讲的
- 小组pre别让用户的页数超时。时长分配写进分工表
- 图表里的文字语言要和最终提交语言一致
- 讲稿时长要在翻译后重新核对，中英文的语速不同
