# 考试提纲细则

怎么按考试规则整理可打印的提纲：规则对应什么产出、内容从哪来、每种怎么写、tex怎么写、编译失败怎么改。考试提纲工作流用。目录和命名见[data-layout.md](data-layout.md)。

## 规则对应的产出

先问清考试规则，再决定做什么。规则只听用户的，不替用户假设。

| 考试规则 | 产出 | 模板 | 示例 |
|---|---|---|---|
| 可以携带纸质材料 | 开卷提纲：全、可索引 | [exam-open.template.tex](../assets/templates/exam-open.template.tex) | [open_example.tex](../assets/examples/exams/open_example.tex) |
| 只能携带一张A4纸质材料 | 小抄：一页，信息密度最高 | [exam-sheet.template.tex](../assets/templates/exam-sheet.template.tex) | [sheet_example.tex](../assets/examples/exams/sheet_example.tex) |
| 只能携带教材 | 教材查阅指南：告诉用户每个考点在教材哪一页 | [exam-textbook.template.tex](../assets/templates/exam-textbook.template.tex) | [textbook_example.tex](../assets/examples/exams/textbook_example.tex) |
| 全闭卷 | 背诵稿加填空版，两份来自同一个tex | [exam-closed.template.tex](../assets/templates/exam-closed.template.tex) | [closed_example.tex](../assets/examples/exams/closed_example.tex) |
| 用户自定义 | 先问清具体限制，套上面最接近的一种 | 同上 | 同上 |

- 自定义规则的例子：“可以带3页A4”按小抄处理，页数上限改成3；“可以带两面A4”算两页；“只许带一本词典”按全闭卷处理
- 全闭卷只出背诵稿和填空版。不出小抄，也不出任何能带进考场的东西。规则就是规则，说明一句“这门课全闭卷，所以只做背诵稿”即可，不展开劝说
- 用户想要的东西与规则冲突时（如全闭卷却要小抄），指出规则不允许，改做背诵稿
- 规则不确定时让用户去查课程大纲或问老师，不猜

## 内容从哪来

- 只用讲义的“查阅”部分（关键术语、考点、小测、出处）和`讲义目录.md`的考点权重，再加`错题本.md`和往年题草稿。不凭记忆添加，不引入资料之外的内容
- 术语、定义、公式、符号按课程资料原样。公式本来就是LaTeX，直接放进tex，不改写
- 范围按用户给的考试范围；没有给时按讲义全部，并告诉用户
- 取舍按考点权重：高权重必须有，中权重放得下就放，低权重最后放。往年题考过的点、错题本里反复错的点优先
- 出处页码：开卷提纲要带；教材查阅指南用教材上印的页码，不用PDF页码，见下

## 各产出怎么写

### 开卷提纲

- 目标是考场上最快找到，所以要全，宁多勿漏
- 按讲义章节顺序，一个知识点一个`\section`，每个都有`\label`
- 每个知识点写：出处和权重、定义、公式（每个符号的含义）、要点、例题思路
- 文末三张速查表：术语速查、公式速查、题型速查，页码用`\pageref`指向对应知识点的`\label`，编译脚本会多编译几遍让页码稳定
- 目录由模板自动生成，PDF里还有书签，可以点击跳转

### 小抄

- 目标是信息密度最高，所以只放高、中权重的点，一条要点一行，能用公式不用句子，能用符号不用字
- 用`\hd{知识点}`加几条`\item`，公式用行内`$...$`，不用`\[ \]`
- 编译时加`--max-pages 1`（规则允许的页数），脚本超页时自动缩小字号、行距和页边距
- 看编译结果里的`last_page_fill`：小于0.7说明还有空间，按权重补内容；脚本只会缩小，不会放大
- 字号缩到7pt以下，脚本会警告可能难以辨认，这时删低权重内容，别硬缩
- 还是超页（`overflow`）就删内容：先删低权重，再删中权重里往年题没考过的

### 教材查阅指南

- 笔记不让带，所以不抄教材内容，只告诉用户去哪找、找什么
- 每个考点一行：考点、教材位置（章节加页码）、在那里找什么（公式编号、例题编号、图表编号）、权重
- 页码用教材上印的页码。Paddle引擎的草稿标记里带书页码（`<!-- p.061 | 书p.46 -->`），直接用；OXR引擎没有，章节号和小节标题照写，页码处写“需核对”，并告诉用户
- 附录里的表（分布表、公式表）单独列出位置，考试可能要查，见[material-processing.md](material-processing.md)

### 闭卷背诵稿和填空版

- 目标是背得下来，所以按权重从高到低分块，一块十来分钟能背完
- 背诵稿和填空版是同一个tex：关键词用`\kw{}`包起来，背诵稿里是加粗，填空版里变成下划线空白
- `\kw{}`只包一个短关键词（不超过8个字），因为填空版的空白不能折行；一句话里的几个关键词分别包
- 对比类内容（A和B的区别）写成表格，更好背
- 编译两次：`compile_tex.py x.tex`出背诵稿，`compile_tex.py x.tex --fill`出填空版（文件名自动加“_填空版”）
- 用户背完后用填空版自测，错的写进`错题本.md`

## tex怎么写

- 从模板复制一份开始，只改标题信息和正文。导言区（`\begin{document}`之前）不要动，不要自己加宏包和宏，不引入外部图片
- 模板里的占位符用【 】包着，替换时连括号一起去掉。没替换完的占位符会原样印进PDF，编译前扫一遍有没有残留的【
- 公式放在`$...$`或`\[ \]`里，数学环境里不要放汉字（字体里没有，会缺字）；公式里要写汉字时用`\text{}`
- 公式外这些字符要转义：

| 想写 | tex里写 |
|---|---|
| % | `\%` |
| & | `\&` |
| # | `\#` |
| _ | `\_` |
| $ | `\$` |
| ^ | `\^{}` |
| ~ | `\~{}` |
| { } | `\{` `\}` |
| 反斜杠 | `\textbackslash{}` |

- 引号用中文引号“ ”，破折号等标点用中文标点
- 列表用`itemize`和`enumerate`；表格用`tabular`（短）或`longtable`（会跨页）；表格里的`&`是列分隔，正文里的`&`要转义
- 中文和英文、数字之间不加空格
- 不要用`\newcommand`新建宏，不要改字号命令；需要强调用`\textbf{}`或`\kw{}`

## 编译和修错

```bash
python scripts/compile_tex.py <文件>.tex                  # 开卷提纲、教材查阅指南、闭卷背诵稿
python scripts/compile_tex.py <文件>.tex --max-pages 1    # 小抄，限一页
python scripts/compile_tex.py <文件>.tex --fill           # 闭卷填空版
```

脚本参数和退出码见[setup.md](setup.md)。输出是JSON，读这几个字段：

| 字段 | 含义 | 怎么办 |
|---|---|---|
| `status: ok` | 编译成功，`pdf`是输出路径，`pages`是页数 | 看`warnings`，没有就交付 |
| `status: error` | 编译失败，`errors`里有行号、错误信息和出错那行的内容，`hints`是常见原因 | 按行号改tex，改完重新编译，最多改5轮；第一个错误往往引出后面一串，先只改第一个 |
| `status: overflow` | 缩到最小字号仍超页 | 删低权重内容，不要硬缩 |
| `status: no_engine` | 没装xelatex | 见下，tex已保存，装好后再编译 |
| `warnings` | 缺字、行宽溢出、引用不存在 | 缺字：换成常见字符；行宽溢出：拆开过长的公式或表格 |

- 修错时只改出错的地方，不重写整个文件，否则会引入新错误
- 5轮仍编译不过：保留tex，把最后的错误告诉用户，让用户决定，不要无限重试
- 没装xelatex：告诉用户tex源文件已经保存；建议按平台安装（Windows `winget install MiKTeX.MiKTeX`，macOS `brew install --cask mactex-no-gui`，Linux `sudo apt install texlive-xetex texlive-lang-chinese`，装完重开终端），装好后再编译。MiKTeX首次编译会自动下载缺少的宏包，需要联网，可能慢几分钟。不做备选的渲染路线

## 编译后检查

- PDF页数符合规则（小抄不超页，开卷看页数是否合理）
- `warnings`为空，或者逐条解释过
- 没有残留的占位符【
- 填空版和背诵稿的内容一致，只差关键词
- 开卷提纲的速查表页码不是“??”（说明还需要再编译一遍）
- 告诉用户PDF的路径，建议打印前先自己翻一遍；agent不能保证每个公式的版面都完美

## 坑点

- 小抄信息密度高，一个符号写错就会误导用户在考场上用错。公式从讲义原样搬，不重新推
- 开卷提纲不是把讲义复制一遍：要加速查表和页码，否则考场上还是找不到
- 教材查阅指南里的页码是最容易出错的信息。拿不准的页码写“需核对”，不要编
- 把规则当成建议是错的：规则允许带什么才做什么，不替用户冒险
- 一个知识点没有讲义（资料缺失）时，在提纲里标“资料缺失”，不补内容
- tex路径含中文没有问题，脚本会用临时的ASCII目录编译
- 模板里的`fontset=windows`不用改：`compile_tex.py`按平台自动换成`mac`或`fandol`字体集。各平台字体宽度略有差别，小抄限页数时以当前平台编译结果为准
