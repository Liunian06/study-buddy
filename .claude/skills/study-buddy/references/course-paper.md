# 课程论文细则

课程论文的结构、引用格式、文献检索与核实。课程论文用。分工见[group-work.md](group-work.md)，语言、翻译、画图、自查、转格式见[deliverables.md](deliverables.md)。

## 结构

默认按GB/T 7713.1—2006的学术论文结构；作业要求另有规定时，以要求为准：

| 部分 | 说明 |
|---|---|
| 题目 | 准确概括论点，不用问句凑数 |
| 摘要 | 目的、方法、结果、结论四点，字数按要求，没规定约200–300字 |
| 关键词 | 3–5个 |
| 引言 | 问题背景、研究问题、本文做什么 |
| 正文 | 按论点分节，每节一个分论点，节间有过渡 |
| 结论 | 回答引言的问题，不引入新材料 |
| 参考文献 | 只列正文引用过的 |

- 课程论文不要求原创研究。通常是文献综述、案例分析或对课程理论的应用，按作业要求判断是哪一种
- 字数分配写进大纲：引言约10%，结论约10%，其余给正文，摘要和参考文献不计字数（作业另有规定的除外）

## 选题与论点

- 给2–3个选题或论点方案，每个附一句理由和可用的资料来源，由用户选或另给方向
- 论点要能被论据支撑，课程理论能直接套用的优先，写起来最省力
- 用户的方向是后面所有写作的依据，不自行改论点

## 引用格式

默认用GB/T 7714—2015的顺序编码制，老师有要求时以老师为准（常见的还有APA、Harvard，老师指定则照做）。

文献类型标识：[J]期刊、[M]图书、[D]学位论文、[C]会议录、[P]专利、[EB/OL]网络资源。

| 类型 | 格式 | 示例 |
|---|---|---|
| 期刊[J] | 作者. 题名[J]. 刊名, 年, 卷(期): 页码. | 袁训来, 陈哲, 肖书海, 等. 蓝田生物群: 一个认识多细胞生物起源和早期演化的新窗口[J]. 科学通报, 2012, 57(34): 3219. |
| 图书[M] | 作者. 书名[M]. 版本. 出版地: 出版者, 出版年: 页码. | 陈登原. 国史旧闻: 第1卷[M]. 北京: 中华书局, 2000: 29. |
| 网络资源[EB/OL] | 作者. 题名[EB/OL]. (发布或更新日期)[引用日期]. 获取和访问路径. | 萧钰. 出版业信息化迈入快车道[EB/OL]. (2001-12-19)[2002-04-15]. http://www.creader.com/news/20011219/200112190019.html. |

- 作者不超过3人时全部列出；超过3人时只写前3位，后接“, 等”，外文文献接“, et al”
- 图书第1版不写版本项，其他版本写“2版”
- 网络资源没有发布日期时，可以省去圆括号部分，方括号里的引用日期必须保留
- 正文里用方括号上标或行内序号，如[1]，序号按首次出现的顺序编
- 同一篇论文里格式必须统一

【待补充：以上著录细则来自二手介绍页（readwonders.com），未对照标准原文。该页提到存在2025年的新版，用户的学校或老师要求用哪一版，需要用户确认；条目的细则以标准原文或老师给的模板为准】

## 文献检索与核实

- 用户提供的文献优先使用
- 不够时给检索关键词和渠道：知网、万方、维普、Google Scholar（经学校图书馆访问），也可以用网络搜索
- 只引用真实存在、核实过的文献。核实指能查到题名、作者、年份、出处，并确认内容与引用处相符
- 没核实的文献明确标注“未核实”，不放进参考文献，不编造作者、页码、DOI
- 引用的论点要对得上原文，不凭记忆概括

## 写作

- 一节一个分论点，开头一句话亮出这一节的结论，再给论据
- 用课程讲义里的理论和术语作分析框架，术语以讲义原文为准
- 引用他人观点时标注序号，自己的判断不加序号
- 图表有编号和标题，正文里引用到，来源写在图下

## 修改

- 用户提意见，agent改，每一版另存为`-2`、`-3`，保留历史，见[data-layout.md](data-layout.md)
- 每一版定稿前自查字数、结构、格式、引用格式是否统一、评分点是否覆盖

## 坑点

- 字数要求通常不含参考文献和附录，以作业要求为准
- 翻译成英文后，参考文献改成英文通行格式，见[deliverables.md](deliverables.md)
- 小组论文只写用户负责的章节，口径与全组一致
