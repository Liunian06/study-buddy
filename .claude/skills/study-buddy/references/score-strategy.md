# 得分策略

怎么算一门课离目标还差多少分、哪些考核值得做、做到什么程度。学期规划和期末速通用。默认目标是保过，不是高分，也不是学懂；用户可以按课程设“高分”目标。

## 目标

每门课有一个目标，写在该课`课程信息.md`的“目标”一栏：

| 目标 | 含义 | 差距按什么线算 |
|---|---|---|
| 保过（默认） | 越过及格线并留余量 | 及格线 |
| 高分（目标分N） | 冲刺具体分数，如85 | 目标分N |

- 建课时问一次：这门课保过还是冲高分，冲的话目标多少分。用户没想好或没回答，就按保过记，不追问
- 学期中随时可以改：用户说“这门我想冲90”或“这门保过就行”，直接改该课的`课程信息.md`，再重新生成`学期规划.md`里这门课的行
- 没有“目标”栏的旧`课程信息.md`按保过处理
- 目标是用户自己的决定，不替用户定。用户说“尽量高”但没给数字时，问一个具体分数；仍然不给，就按保过安排，并说明高分需要的时间没法估
- 目标分高于满分或明显不现实（如已出分的部分已经让目标不可达）时，如实说，不照单全收

## 及格线

- 默认按百分制60分。有的课不同（如70分、等级制C），按课程修改，写进该课的`课程信息.md`
- 有的课要求期末卷面单独及格（总分及格但期末不及格仍算挂）。要问用户或查课程大纲，不要默认没有。有这条的课，期末不能放弃，在及格路径里单独标出
- 评分构成是可选信息，学期末才最终评定，什么时候给都行，不催。没有就不算及格路径，不要猜比例；任务照常全力做，评分构成只影响排期和优先级，不影响单项任务做到什么程度

## 计算差距

对每门课：

1. 已得加权分 = 各已出分考核的得分 × 权重之和
2. 还差分数 = 目标线 − 已得加权分。目标线：保过课是及格线，高分课是目标分
3. 未完成考核的可争取分 = 各项权重 × 该项预期得分率

预期得分率怎么估取决于目标：

- 保过课：对该项“做到及格水平”的估计，不是满分。没有已得成绩时，每项先按60%估，再按用户的实际水平调整
- 高分课：不用60%。按用户过往成绩（同课已出分的考核、往年题模拟分）估；没有依据就问用户“你觉得这类考核自己大概能拿多少”，仍然没有就按70%暂估并标“暂估”。预期得分率只反映现有水平，目标分与它之间的缺口，才是需要靠额外投入补上的部分

## 考核性价比

| 考核类型 | 单位时间拿分的特点 | 做法 |
|---|---|---|
| 作业、case study、task | 有明确要求和评分点，肯花时间基本能拿到及格分 | 优先保证，完整做完 |
| presentation | 评分偏重结构、表达、时间控制，内容深度要求较低 | 优先保证 |
| 课程论文 | 篇幅大，但格式、结构、引用规范都能拿到基础分 | 保证交，按评分点做到位 |
| 期末考试 | 范围大、一次定胜负；往年题和考点信号能显著缩小范围 | 权重大时必须保，用速通计划 |
| 随堂测验、出勤 | 单项权重小，成本低 | 能拿则拿，不专门准备 |

上表是常见规律，不是定律。用户课程的实际评分标准与此不同时，以课程为准。

高分课的做法不同：目标分比及格线高，每一项都要往高档去做，表里“拿到及格分”的判断不再成立。

| 考核类型 | 高分课的做法 |
|---|---|
| 作业、case study、task | 按评分标准的最高档去写，逐条对照评分点自查 |
| presentation | 结构和表达之外，内容深度和回答提问的准备也要做 |
| 课程论文 | 论点、论证和引用质量都要过关，不止格式和结构 |
| 期末考试 | 在覆盖考点之外加深度和题型训练，见[exam-cramming.md](exam-cramming.md) |
| 随堂测验、出勤 | 全部拿满，成本低 |

## 保过方案

- 目标是让每门课的“已得加权分 + 各项可争取分”刚好越过及格线并留一点余量（建议留5–10分的余量，是经验做法，防止评分偏低）
- 时间够就每项都做满。只有按最低投入也排不下时，才在满足及格线的前提下建议放弃性价比最低的项（权重小、准备成本高、容易失分），是否放弃由用户决定
- 每门课输出：必须做的考核、各做到什么程度、可以放弃的考核（时间排不下时才有）、期末是否要单独及格
- 某门课即使全做也过不了线时，如实告诉用户，并指出差多少分、补救余地在哪（补考、重修规则要用户去查，不要编造学校规则）

## 高分方案

- 所有课先排到保过线，剩余时间再分给高分课。保过是底线，高分是在此之上的投入，不能为了冲高分让别的课掉到及格线以下
- 剩余时间按“每多花1小时能多拿几分”分给高分课。通常期末考试和权重大的论文边际收益更高，权重小又难拿满的项边际收益低
- 高分课不建议放弃任何考核
- 目标分和可用时间对不上时，如实说：目标分是多少、按现有水平还差多少、大概需要额外多少小时（用[semester-planning.md](semester-planning.md)的最低小时数表估，标“估算”），由用户决定降低目标、减少别的课的投入，还是接受达不到的风险。不假装能达成
- 每门课输出：目标线与差距、各项考核要做到什么档次、额外投入的小时数、期末是否要单独及格

## 坑点

- 权重的合计不一定是100%：有的课有加分项或平时分另算，以课程大纲为准
- 已出分的成绩可能是暂定的，用户说“大概”时按用户说的写，并标“暂定”
- 不要因为目标是保过就建议用户不交作业：未交通常按0分算，是最差的性价比
- 不确定的学校规则（补考、缓考、成绩更正）标注“需用户核实”，不当作结论
