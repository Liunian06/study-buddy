# 学习搭子使用指南

帮你用最少的时间让每门课都及格：整理课件、规划每周、带学、考前速通，作业和论文直接做出完整成品。

## 能做什么

| 你想要 | 怎么说 | 得到什么 |
|---|---|---|
| 整理老师发的资料或教材 | “老师发了一堆课件，帮我整理一下”“这是教材，帮我整理” | 按知识点排好的讲义和目录 |
| 搞清这门课怎么及格 | “这学期怎么安排”“这门课怎么才能及格” | 每门课的及格路径、每周要做什么 |
| 按讲义学一节 | “带我学下一节” | 白话讲解、小测、错题本 |
| 考前复习 | “后天考试” | 速通计划、模拟卷、考前速记清单 |
| 做pre | “下周要做pre” | 大纲、讲稿、Q&A、pptx |
| 写课程论文 | “要交一篇3000字的论文” | 完整论文，转成你要交的格式 |
| 做其他作业 | “这个case study怎么写”“帮我做这个task” | 完整作业，转成你要交的格式 |

## 使用过程

1. 第一次使用：先把一门课的资料交给我。我会列出文件让你确认范围和顺序，再整理成讲义，并让你确认章节划分
2. 你需要提供：评分构成、截止时间、已有成绩（口述或给大纲文件）。我据此算每门课离及格差多少、每周做什么
3. 做作业类时：我会先问你这次用什么语言提交（每次都问）、个人还是小组。小组只做你负责的部分，会先出分工表请你确认
4. 过程中的稿子都用中文，你审完后我再翻译成提交语言，最后转成你要的格式
5. 第一次整理资料前，需要你在`study-buddy-data/config.json`里填好VLM服务（用来转写课件里的图片）；不填也能用，只是图片里的内容不会被转写

## 数据保存在哪

所有产出在`<工作目录>/study-buddy-data/`：

- `config.json`：接口配置，含你自己填的key
- `学期规划.md`：当前学期的课程、及格路径、每周清单
- `0101_微观经济学/`等课程文件夹：前两位是学期号（大一上01，大四下08），后两位是课程序号；里面有讲义`讲义/`、`讲义目录.md`、错题本、速通计划，以及`演示文稿/`、`论文/`、`作业/`

每门课的文件夹里有`原始资料/`和`课程资料/`：把老师发的原始课件放进`原始资料/`，我不会改动它们；整理时我会复制一份到`课程资料/`并改成规范的名字，后续处理都读这份副本。

## 需要知道的限制

- 目标是及格，不追求高分或学透；不讲课程知识在产业里怎么用
- 考试或限时测验进行中，我不代答。考前复习、模拟照常帮忙
- 不做选课咨询和职业规划
- 依赖Windows和Office：转换PPT和DOC、生成pptx需要
- 课件会上传到OCR引擎（默认百度Paddle，需要你申请免费key；没有key时退用SoMark的OXR），图片会发给你配置的VLM服务商
- 最低小时数是经验估算，会随你的实际完成情况校准
- 论文引用格式的细则（GB/T 7714）来自二手资料，没对照标准原文，老师有模板时以模板为准
